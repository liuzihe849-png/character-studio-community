CHARACTER STUDIO

从一个动态主体开始

没有找到匹配的作品，试试其他名称。

① 在 Codex 中确认设计

提供参考与要求，先确认静态海报，再确认动态预览。让 Codex 按本编辑器项目格式准备完整素材、图层和运动数据。

② 打开可编辑项目包 ZIP

仅接受包含 project.json 和 PNG 素材的 Character Studio 项目包。已确认的文字、字符与动画参数随项目载入；模板也可以直接使用。

③ 精调、保存与导出

选中主体、文字或其他元素，调整实际支持的字符与动效。PNG 是静态成品；MP4 是动态成片，两者都不能恢复为完整可编辑项目。请用“备份项目”保留项目包。

单张图片没有图层或三维运动数据，普通源代码 ZIP 也不是项目包。参数 JSON 仅恢复对应项目的设置。当前版本不能导入任意渲染器代码。

从已确认的设计开始

这里负责把设计调到合适的字符质感和运动节奏。新主题先在 Codex 中确认静态海报和动态预览，再带着项目回来。
CODEX → PROJECT → EDITOR

先确认设计，再精调动画

  1. 在自己的 Codex 中创作

    附上参考，明确主体、文字和哪些元素需要动态。先看静态稿，满意后再做动态预览。

  2. 确认可编辑范围

    确认画面后，再准备与编辑器兼容的图层、素材和运动数据。新主体的三维运动若没有受支持的渲染器，需要先适配和验证，不能直接用旧模板替代。

  3. 载入编辑器

    同一电脑可由 Codex 自动载入；分享或备份使用项目包 ZIP。在这里调字符、速度和已有动效，导出 PNG / MP4。

编辑器内“连接我的 AI”负责局部修改，不会自动继承 Codex 中的创作对话。实验室试作不等于已确认的正式设计。
